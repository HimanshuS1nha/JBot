# JBot

JBot is an AI-powered chat assistant that helps users get answers, generate ideas, create content, and solve everyday problems through natural, conversational interactions.

## Get started

1. Server
   - Copy application.properties.example as application.properties and add all the required values
   - Run the server

   ```bash
   ./mvnw springboot:run
   ```

2. Client
   - Copy .env.example as .env and add all the required values
   - Install dependencies

   ```bash
   npm install
   ```

   - Run the server

   ```bash
   npm run dev
   ```

## Features

- Email password auth flow
- Infinite Loading for conversations and messages
- Searching for conversations
- Auth token handling using keytar

## TECH STACK USED

- Spring Boot
- Spring Security
- Electron
- React
- Tailwind CSS
- ShadCn UI
